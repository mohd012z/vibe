## Latent bugs found (all hidden behind FakeRunner, verified by probing real
r2 6.2.2 output — never hand-rolled from memory)
1. **argv order**: `[r2, path, -c, cmd]` → r2 6.x rejects
   (`ERROR: Cannot open 'aflj'`, rc=1, 0 bytes). Fixed:
   `r2 -e scr.color=0 -e bin.relocs.apply=true -q -c CMD path` (flags before
   path). Added `_run(argv, timeout)` seam for test capture.
2. **ANSI on text output** even non-TTY (`afl` rows wrapped in ESC[0m).
   Runner now strips SGR/OSC (`_strip_ansi`); parsers also strip defensively
   in their text paths.
3. **Command/shape mismatches** (JSON sent, text expected; then text shapes
   changed in 6.x):
   - `aflj` JSON item shape = `{addr, name, size, realsz, ...}` — parsers
     rewritten dual-mode (JSON r2-6 + legacy 3-token text; legacy kept).
   - r2 6 text `afl` = 4-token `addr delta size name` (old parser read
     size-as-name).
   - **`iI` no longer exists** in r2 6 (that's binary info); imports = `ii`
     / `iij` (JSON; **no per-import lib name** in ELF — module stays `''`,
     honest).
   - `iE`/`iEj` lists symtab **and** dynsym → duplicated names; parser now
     dedupes in first-seen order.
   - **`pdj` without `aa` disassembles raw bytes** (`fcn_addr=0`, wrong
     mnemonics) — command is now `aa; pdj N @0xVA`.
   - **bare-hex `@VA` seek is parsed as DECIMAL** (`@1129` → 0x461); must be
     `@0x1129`.
   - r2 6 `pdj` items carry `disasm` (full mnemonic), NOT `name`+`opcode`;
     `parse_disasm` now handles both shapes.
   - **`aXR` removed in r2 6**; xrefs = `axt`/`axtj`.
4. **PIC `.so` xref routing**: in a position-independent `.so`, `sum3` calls
   `add` **through the PLT stub** (`sym.plt.add @0x1040`); `axtj` on the real
   function address returns empty. `xrefs_of` now falls back to the matching
   `sym.plt.<name>` stub when the direct query is empty (documented as a PIC
   calling-convention artifact, E3 either way).

## Evidence (all probed on real 6.2.2, real gcc x86_64 .so)
- `aa; aflj` → 14 fns incl `sym.add/mul/sum3/plt.add` (JSON, keys locked).
- `iEj` → 8 items, dupes confirmed (symtab+dynsym); `iij` → 6 imports
  (free/malloc/strdup/__cxa_finalize + _ITM_*/__gmon weak).
- `aa; pdj 20 @0x1129` → `push rbp / mov rbp, rsp / ...` with `fcn_addr=4393`;
  without `aa` → `add byte [rax], al` junk.
- `aa; axtj 0x1040` → `[{"from":4459,"opcode":"call sym.plt.add",
  "fcn_name":"sym.sum3"}]`; `aa; axtj 0x1129` → `[]`.
- `axtj` JSON keys: `from, type, perm, opcode, fcn_addr, fcn_name, realname,
  refname`.
- Fixtures in the test are the **captured** shapes (trimmed), not invented.
